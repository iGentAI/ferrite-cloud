# Support

Problems with the hosted Ferrite platform are reported as issues in this repository, at <https://github.com/iGentAI/ferrite-cloud/issues>, or by email to info@igent.ai. Use email when the report includes anything you would not want public, such as an account address or the contents of an application.

A report we can act on says:

- what you were doing, and with which agent or CLI version (`ferrite --version` prints it);
- what you expected and what happened instead, with the exact error text;
- the application's address or name, and roughly when it happened, so the request can be found in the logs.

Leave tokens, passwords and other secrets out of an issue. If a secret has already been posted, change it first and then tell us.

A problem in one of the other repositories, such as a package or an example, is best reported in that repository. Security problems go to security@ferrite.cloud and never into a public issue; see `SECURITY.md`.

The [documentation](https://docs.ferrite.cloud) and its knowledge base answer the common questions about deployments, sign-in and billing.
